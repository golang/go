## Findings and minimum correction

1. **Build limits reach the runtime tests.**
   `release-acceptance.sh:98` exports `GOMAXPROCS=2`, `GOGC=50`,
   `GOMEMLIMIT=2GiB`, and `GOFLAGS=-p=2`; line 110 clears only compiler flags
   after make. The two unchanged memory-limit tests at `runtime/gc_test.go:773`
   and `:787` do run on this host. Their child at
   `runtime/testdata/testprog/gc.go:325` reports `insufficient CPUs` because the
   inherited previous GOMAXPROCS is 2. The child next requires an initial
   unlimited memory limit. Removing only the CPU cap would expose the
   inherited 2 GiB limit; this second failure is inferred from source, not an
   executed result. Scope these settings to make, or unset all four immediately
   after make. Later acceptance commands already specify compile parallelism.
   Do not lower runtime GOMAXPROCS to control compiler concurrency.

2. **C and C++ use different GCC releases.**
   `release-acceptance.sh:120` selects GCC 14 for CC but leaves CXX at its
   default. The SWIG LTO children use `/usr/bin/g++` 13.1 to link objects
   generated by GCC 14, and both `TestCall/lto` and `TestCallback/lto` fail with
   the explicit LTO version mismatch. `swig_test.go:70` obtains the compiler
   through `go env CXX`. Resolve `g++-14` alongside `gcc-14`, fail if either is
   absent, and export paired CC/CXX paths. Keep assignment and export separate
   so a failed lookup propagates. Record both compiler versions. Retain the
   existing C23 probe and do not force CGO globally for cross-target fixtures.

3. **Test fixtures lie outside the declared local temporary root.**
   `release-acceptance.sh:96` makes TMPDIR and GOTMPDIR siblings. Go 1.27
   `testing.T.TempDir` uses GOTMPDIR (`testing/testing.go:1615`), while unchanged
   `work/security.go:560` recognizes CWD, GOMODCACHE, and `os.TempDir()` as
   local roots. The security attacks created under GOTMPDIR are therefore
   classified as nonlocal and intentionally bypass file inspection. This
   explains all five failing families: sysroot flags, Wl flags, input files,
   COFF directives, and object sections. Set GOTMPDIR to a directory inside
   TMPDIR, such as `$job_root/tmp/go-tmp`, and create both before use. Keep both
   outside the checkout and on the existing disk. This restores the tests to
   the declared security boundary; it neither changes the boundary nor claims
   support for arbitrary separately rooted GOTMPDIR values.

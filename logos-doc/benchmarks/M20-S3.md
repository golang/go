# M20-S3: package-wide cgo call contracts

This draft implements [RFC-306, section 3.6.3](../SPEC.md#363-package-wide-cgo-contracts)
on top of M20-S2. `logoscgoopt` remains disabled by default. Full validation and
G6 acceptance are pending; no speedup or completed milestone is claimed.

## Decision and invariant

Cgo parses every input before translating and emitting files one at a time.
Its final generated Go wrappers already use all package callback and escape
directives. An earlier file's C wrapper previously saw only the contracts
recorded up to that input, so an otherwise eligible result frame could retain
both stack-top lookups solely because its directive appeared later.

After the parse queue joins, `logosCollectCgoContracts` copies only the parsed
`NoCallbacks` and `NoEscapes` maps into the existing package maps. It is gated
by `logoscgoopt` and excluded from gccgo and godefs. The helper and hook add
fewer than 50 production lines and have one metadata-ordering concern, so G6's
single-candidate exception applies.

The invariant is that the collected metadata equals the eventual union of
the original `Record` calls. Neither translation nor declaration recording
moves. Each file keeps its own C preamble, macro definitions, and names.
Unmatched-directive validation still runs after all inputs. The final
generated Go files must be byte-identical for a fixed fast-cgo setting.
Runtime entry, callback guards, pointer checks, escape uses, and keepalives
therefore retain their existing decisions.

The existing stable-frame proof and its runtime regressions remain in
[M20-S2](M20-S2.md). This slice only supplies previously parsed contracts to
the same predicate sooner. It does not infer C effects or relax a contract.

The Go input is bounded to 1023, the second argument is one, and a package
sink observes the final value. The function declaration and call appear in
an earlier source than its sole `nocallback` directive. This isolates a case
M20-S2 could not specialize. The arithmetic test separately covers unsigned
wraparound, which is defined in both languages.

`misc/cgo/manifest.json` declares this as a separate target. The CI benchmark
runner builds baseline, candidate, and fresh integration binaries, calibrates
and freezes a count per exact row, then records one scored campaign. Noise
failure is a blocked result, not a retry until acceptance. The same-contract
latency floor remains unestablished.

## Reproduction

Build the fork from `src` with `./make.bash`, put its `bin` directory first on
`PATH`, and keep `GOTOOLCHAIN=local`. Install gcc, gccgo, and clang as required
by the dedicated workflow. The complete CI commands and evidence formats live
in `.github/workflows/cgo.yml` and `misc/cgo`.

The focused generated-code entry point is:

```sh
GOEXPERIMENT=logoscgoopt,nologosfastcgo go test -count=1 \
  -run='^TestCgoOptPackageContracts$' cmd/cgo/internal/testlogos
```

The test itself exercises all four optimization settings and both input
orders. For performance, run `misc/cgo/benchmark.mjs` with the verified
`HYPERFINE` binary and a new evidence directory. Do not replace fixed work with
independent adaptive timings or combine rows.

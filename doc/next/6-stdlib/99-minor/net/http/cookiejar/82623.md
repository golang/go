[Jar] now follows more of the cookie storage rules of
[RFC 6265bis](https://datatracker.ietf.org/doc/html/draft-ietf-httpbis-rfc6265bis-22),
as browsers do.
It ignores a Secure cookie set from an insecure origin, and a cookie that
is not Secure, set from an insecure origin, that would overwrite or shadow
a Secure cookie of the same name. HTTPS URLs are secure origins, and so
are localhost and loopback addresses over HTTP.

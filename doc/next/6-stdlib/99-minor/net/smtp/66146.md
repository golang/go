[Client.Mail], [Client.Rcpt], [Client.Verify], and [SendMail] now check
addresses before sending them, so that an address can no longer add
parameters to a command. An address must be an RFC 5321 mailbox, which
may contain UTF-8 as RFC 6531 allows, or a local part alone. Addresses
with spaces outside quotes, display names (as in `Name <user@example.com>`),
or '<' or '>' anywhere are rejected. [Client.Hello] likewise requires an
ASCII domain name or an address literal.

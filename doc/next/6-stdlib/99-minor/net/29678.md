The [IPMask] and [HardwareAddr] types now implement
[encoding.TextMarshaler] and [encoding.TextUnmarshaler].
The UnmarshalText methods recognize the current marshaling
of those types, as well as a planned future marshaling format.
The future marshaling format will be readable in JSON format,
unlike the current format which is a base64 encoding.
The MarshalText methods still use the current format by default;
the future format can be selected with the `netmarshal` [GODEBUG setting](/doc/godebug),
and will become the default in a later Go release.
This is being done as a two-step process so that JSON generated
by this release of Go can still be read by earlier releases of Go.

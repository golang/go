The new [Counter] type is a sharded counter of int64, uint64, or float64
values that is optimized for frequent concurrent calls to [Counter.Add] and
infrequent calls to [Counter.Value]. Updates are spread across per-processor
shards, so Add remains fast even when many goroutines update the same counter,
while Value sums the shards and takes time proportional to GOMAXPROCS.
The zero value of a Counter is ready to use.

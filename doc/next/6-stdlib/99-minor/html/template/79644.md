A template action in the content attribute of a meta element is now also
filtered as a URL when it follows a refresh delay with no `url=`, as in
`content="0; {{.}}"` or `content="0,{{.}}"`, because browsers read that
position as the refresh URL. This does not apply when an earlier name,
property or itemprop attribute, or an http-equiv attribute other than
refresh, shows that the element is not a refresh. The
`htmlmetacontenturlescape=0` setting turns this off along with the existing
`url=` filtering.
